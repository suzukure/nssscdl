# 用語集

| 用語 | 定義 |
|---|---|
| 生徒 | 個人レッスンを予約する利用者。 |
| スクール管理者 | 講師・運営者として業務管理を行うアプリケーション上の管理ロール。 |
| システム保守担当者 | 技術基盤、監視、バックアップ、障害復旧を担当するロール。 |
| 個人レッスン | 本システムで生徒が予約する1対1の90分レッスン。 |
| 標準レッスン | 月間標準回数N以内に分類された予約。初期値N=3。 |
| 追加レッスン | 同月の標準回数を超えた予約。予約は禁止しない。 |
| 欠席 | 事前キャンセルされず、レッスン終了後にスクール管理者が「参加しなかった」と記録した状態。旧称は廃止し、本仕様では「欠席」に統一する。 |
| 生徒キャンセル | 生徒がレッスン終了時刻までに行う予約取消。開始前なら枠を再開放し、開始後〜終了までは再開放しない。 |
| スクール都合キャンセル | 休業等によりスクール側が確定予約を取消すこと。 |
| 管理者確保枠 | スクールが別用途で使用するため、個人レッスン予約を受け付けない固定枠。生徒予約ではない。 |
| グループレッスン枠 | 管理者確保枠のうち理由が「グループレッスン」で、生徒画面にもその旨を表示する枠。内容・参加者等は本システムの対象外。 |
| 休業／枠無効化 | その日時にレッスン枠自体を提供しない状態。管理者確保とは別概念。 |
| 公開済みスケジュール | 生徒が閲覧・予約できる状態にした月間スケジュール。 |
| 連絡先メール | 生徒への連絡およびマジックリンク送信先。Activeな生徒間で一意。 |
| Google認証メール | Google認証で得られるメール。連絡先メールと異なってもよい。 |
| 学生ID／生徒ID | システム内部の主たる生徒識別子。メールやGoogle IDを主キーとしない。 |
| 利用停止 | 乗っ取り疑い等への一時的セキュリティ措置。退会・休会ではない。 |
| 削除 | 生徒アカウントを恒久的に無効化し、氏名・連絡先メール・認証識別子等の直接管理する個人情報を削除・匿名化する処理。 |
| 正本表示 | システム内部で確定した業務状態を画面で確認できること。 |
| RPO | 許容可能なデータ損失時間。 |
| RTO | 重大障害からサービス復旧までの目標時間。 |
